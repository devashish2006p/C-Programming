# 1. Data Structure
Data ko organize, store aur efficiently access/process karne ka ek systematic tareeka hota hai.

## Importance and Need for Data Structures
1. Data structures help in organizing and storing data systematically.
2. They enable faster access, searching, insertion, and deletion of data.
3. They help in efficient memory utilization.
4. They improve the performance and efficiency of programs.
5. They are essential for solving complex problems and developing efficient software applications.

## Relationship between Data Structure and Algorithms
Data Structure data ko organize aur store karne ka tareeka hai, jabki Algorithm us data par kisi problem ko solve karne ke liye step-by-step instructions ka set hota hai; dono milkar program ko efficient aur fast banate hain.

# 2. Classification of Data Structures
## 1. Primitive Data Structure 
Aisa basic data structure jo single value store karti hai. 
Ex - 
  1. int - used to store whole number.
  2. float - used for storing decimal number.
  3. char - used for storing single character.
  4. bool - stores true or false values.

## 2. Non-Primitive Data Structures
Aisi data structure jo multiple values ko organize aur store karti hai. Ex - 
  1. Arrays - Collection of elements of the same type stored in contiguous memory.
  2. Linked List - Elements (nodes) connected by pointers, allowing dynamic memory allocation.
  3. Stacks - Follows Last-In-First-Out (LIFO) principle, used for function calls and undo operations.
  4. Queues - Follows First-In-First-Out (FIFO) principle, used for scheduling tasks.
  5. Trees - Hierarchical data structure with nodes representating elements.
  6. Graphs - Set of nodes connected by edges, representing relationships.

### Linear Vs Non-Linear Data Structures 
1. Linear Data Structures - Data is arranged sequentially. Ex - Arrays, Linked List, Stacks and Queue.
2. Non-Linear Data Structures - Data is organized in a hierarchical interconnected manner.

# 3. Data Structure Operations
Basic Operations on Data Structures :- 
1. Traversing - Accessing elements in a data structure.
2. Searching - Finding a specific element.
3. Insertion - Adding a new element.
4. Deletion - Removing an element.
5. Sorting - Arranging elements in an order.
6. Merging - Combining two datasets.

# 4. Introduction to Algorithm 
Kisi problem ko solve karne ya kisi task ko complete karne ke liye step-by-step instructions ka finite set algorithm kehlata hai.
## Algorithm design Basics
  1. Problem Understanding: Sabse pehle problem ko dhyan se samjho aur clearly define karo.
  2. Input/Output Definition: Decide karo algorithm ka input kya hoga aur expected output kya generate hoga.
  3. High-Level Approach: Problem ko chhote sub-problems me divide karo aur step-by-step solution ka plan banao.
  4. Select Strategy/Paradigm: Problem ke liye suitable design paradigm choose karo jaise divide and conquer, greedy, dynamic programming, ya backtracking.
  5. Detailed Steps: High-level plan ko concrete aur executable steps me convert karo, jo deterministic aur finite ho.
  6. Testing with Examples: Algorithm ko small input examples pe test karo aur correctness verify karo. 
  7. Optimization: Time aur space complexity evaluate karo aur algorithm ko efficient aur practical banao.

## Pseudocode Writing 
Pseudocode writing ek language-independent way hai algorithm ko clearly aur step-by-step represent karne ka, jisse program likhne se pehle logic samajh aata hai.

## Flowchart 
Flowchart ek diagrammatic representation hota hai jisme kisi process, algorithm, ya program ke steps ko symbols aur arrows ke through visually dikhaya jaata hai, taki logic aur flow easily samajh me aaye.

## Symbols & Shapes of Flowchart
| Symbol                              | Shape                       | Use                                                     |
| ----------------------------------- | --------------------------- | ------------------------------------------------------- |
| **Terminator**                      | Oval / Ellipse              | Start ya End point                                      |
| **Process**                         | Rectangle                   | Kisi bhi action ya operation ko represent karta hai     |
| **Decision**                        | Diamond                     | Yes/No ya condition-based branching                     |
| **Input / Output**                  | Parallelogram               | User input ya system output                             |
| **Connector**                       | Small Circle                | Flow ko continue karne ke liye (page ya sub-process me) |
| **Predefined Process / Subroutine** | Rectangle with double lines | Already defined process ko call karna                   |
| **Document**                        | Rectangle with wavy bottom  | Document output ya report                               |
| **Delay / Storage**                 | Half-ellipse / Cylinder     | Delay, storage, database representation                 |
