# 1. Array Operations
1. Traversing - Traversing an array refers to accessing each element sequentially, usually using a loop. This is a basic operation required for reading or updating values in an array.
2. Insertion - Insertion refers to adding a new element at a specific position in an array.
3. Deleting  - Deletion removes an element at a specific index, requiring shifting of elements to fill the gap.
4. Searching.
   1. Linear Search (O(n)) - Traverses the array sequentially to find an element.
   2. Binary Search (O(log n)) - Only works on sorted arrays. Uses divide and conquer by checking the middle element.
5. Sorting.
   1. Bubble Sort (O(n²)) - Repeatedly swaps adjacent elements if they are in the wrong.
   2. Quick Sort (O(n log n)) - Uses recursion and partitioning.
